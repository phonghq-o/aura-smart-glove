# AURA — Wear the Voice. Hear the World.

Official product demo and interactive showcase for the **A.U.R.A.** (Autonomous Universal Recognition Aid) smart glove.

Built for **Bach Khoa Innovation 2026 (BKI26)** — University Category.

## Features
- **Interactive Gesture Studio**: 10-class TinyML gesture sandbox with real-time AMOLED simulation and text-to-speech.
- **Two-Way Communication Architecture**: I Sign (Offline C-LSTM on ESP32-S3) & I Listen (Gemini STT & 3D Sign Avatars).
- **Hardware Anatomy**: Flex sensors, dual-core edge AI processing, ES8311 Hi-Fi audio, and AMOLED display.
- **Minimalist Tech Aesthetic**: Designed with modern responsive Tailwind CSS.
